# Campo Estragado

## Oque é:
Campo Estragado é minha tentativa de refazero jogo do jogo do campo minado no EclipseIDE com java e java swing como tentativa de aprender a usar classes e orientação à objetos e usar janela e sprites para um jogo

## Versão atual: V1.0.0

## Versões anteriores:

### V1.0.0:
- 2026/09/13

- Abre uma janela com o jogo tendo 10 bombas num campo de 5x5

- Se clicar numa bomba, aparece o sprite da bomba e printa "VOCÊ PERDEU!!"

- Sem função de reiniciar, mostrar tiles limpos e seus números, botar bandeiras ou ganhar.
