# Projeto Jaimes & Charllote: Campo Estragado

## Oque é:
Jaimes & Charllote: Campo Estragado é minha tentativa de refazer o jogo do jogo do campo minado no EclipseIDE com java e java swing como tentativa de aprender a usar classes e orientação à objetos e usar janela e sprites para um jogo estilo anos 90 ou seilá.
